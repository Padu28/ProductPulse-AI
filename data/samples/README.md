# data/samples

Small **aggregate** tables (no user-level rows) copied here automatically by
`scripts/export_from_bigquery.py` so that reviewers on GitHub can see the shape of the
results without running BigQuery.

This folder is empty until you run the export. Files that appear here:
`dataset_overview.csv`, `event_overview.csv`, `event_param_keys.csv`, `daily_metrics.csv`,
`user_funnel_by_device.csv`, `session_funnel.csv`, `cohort_retention_monthly.csv`,
`product_performance.csv`, `data_quality.csv`.
